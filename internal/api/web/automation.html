登录 30 秒后启动此便携版，不打开浏览器。需要已登录且解锁的桌面才能开始游戏任务。移动或更新便携目录后，请重新启用以更新路径。

新建每日任务链

选择已经配置好的任务，用 ↑ ↓ 排序。每个任务结束后才开始下一项，整条任务链独占执行器。

执行规则

启动后及运行中持续检查时间。当天已成功的步骤不会因重启或重复点击再次执行；离线多天不会补跑过去的每日任务。

暂停会让当前步骤完成。中断的步骤保留记录，点击“恢复未完成”重试；取消会终止当前步骤。

每步沿用任务的重试和超时设置；未设置超时时使用 1 小时。必须使用实际执行工作的助手命令。只打开设置界面、或启动器退出，都不能证明游戏工作已完成。
